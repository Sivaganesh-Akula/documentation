# Status

## Recording changes on repository

Command: `git status` or `git status -s` for short status

### It have two stages in output

- changes to be committed
- changes not staged for commit

git status -s pre indications

- ?? -> New files that are not tracked
- A -> new files that added to stage area
- M -> modified files
- MM -> modified and staged
- D -> Deleted file
- C -> Copied file
- R -> renamed file
- U -> unmerged - conflict
- ! -> ignored
